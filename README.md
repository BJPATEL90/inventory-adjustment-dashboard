# Inventory Adjustment Monitoring Dashboard
## Mosaic Wellness — GitHub Pages Frontend

**Live URL:** https://bjpatel90.github.io/inventory-adjustment-dashboard/

### Configuration (already set — do not change)
- Google OAuth Client ID: configured in js/auth.js
- Apps Script API URL: configured in js/api.js
- Allowed domain: mosaicwellness.in

### Files
```
index.html          — Main SPA shell
css/styles.css      — Design system
js/auth.js          — Google login + domain check
js/api.js           — Apps Script API client
js/app.js           — Navigation + shared helpers
js/daily.js         — Daily Tracker module
js/mtd.js           — MTD Tracker + charts
js/variance.js      — Variance Tracker + filters
js/remarks.js       — Remarks Tracker
```

### Deployment
Push all files to the main branch. GitHub Pages serves from root.
